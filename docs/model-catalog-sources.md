# Model catalog source verification

Verified against official vendor sources on 2026-11-09. The eight-calendar-month window for that date is 2026-03-09 through 2026-11-09, inclusive. The entries below are a verified starter set for token-based text models, not an exhaustive inventory of every modality or provider. Model IDs are the vendor API IDs; no additional aliases were verified. When a vendor documents only a versioned API ID, use that ID exactly.

Rates are USD per million tokens for standard API usage, unless the row calls out a condition. They cover uncached input and output only. Prompt-cache rates, tool charges, regional/priority tiers, and long-context uplifts are not represented by the catalog's two price fields. A price absent from a candidate means the flat input/output fields would misstate the vendor's terms.

## Exclusions and verification gaps

- `claude-haiku-5-5` is eligible and should remain a curated choice, but its rate must stay unknown in a flat-price catalog. A future schema could add prompt-size tiers; do not approximate the over-100K rate with the cheaper tier.
- Gemini Omni 1.2 Flash launched on 2026-11-05, but it is a video-generation model priced by generated seconds, not input/output tokens. It does not fit this catalog's token pricing fields or the text model menus; see [Google's launch announcement](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/).
- Gemini 4 Carbon was announced for trusted pre-release testing and is not yet a verified generally available API choice. Keep it out until an official API ID, public availability, and pricing are confirmed; see [Google's October 2026 roundup](https://blog.google/innovation-and-ai/technology/ai/google-ai-updates-october-2026/).
- The latest broad review covered OpenAI, Anthropic, and Gemini only. It does not establish that other Gloamy providers have no eligible March-November 2026 models. The bundled starter catalog intentionally omits those unverified families; they remain usable through live discovery and explicit model IDs. Adding their curated entries requires verified current official release dates, exact API IDs, availability, prices, and aliases. Unverifiable release dates exclude candidates.
- No `Codex` subscription/OAuth rate was verified. Unknown rates must remain unknown; cost tracking should continue counting tokens while reporting numeric zero as unknown rather than free.
- Recheck official price pages when updating the bundled catalog. Catalog loading and lookups must remain offline; source URLs and `verified` dates are static review metadata, not a runtime-fetch instruction.
